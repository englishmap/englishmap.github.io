# Brand files

| File                                | Use                                                                        |
| ----------------------------------- | -------------------------------------------------------------------------- |
| `logo.webp`                         | Wide logo on a light background, used at the top of the repository README  |
| `symbol.webp`                       | Square symbol on a dark background, the source of the site icons below     |
| `../../public/apple-touch-icon.png` | 180 px icon for home screens, from `symbol.webp`                           |
| `../../public/og.png`               | 1200 × 630 share image, `symbol.webp` centered on its own background color |
| `../../public/favicon.svg`          | Browser tab icon, drawn by hand in SVG                                     |

The high-resolution originals live in `source/` (`logo-original.jpg`, `symbol-original.webp`), which is not versioned. Regenerate the optimized files from them when the brand changes.
